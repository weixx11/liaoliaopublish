# 料小宝协议与商家端接口

API前缀：`https://home.liaoxiaobao.cn/api`。正式实现：`publisher_app/platforms/liaoxiaobao.py`。既有登录、发布、图片、追加、置顶流程曾由用户逐步测试；最新可选标题/简介/标签字段已从官网前端确认，并完成模拟检查。

## 初始化、加密与签名

1. 随机生成32字节seed，用官网固定RSA公钥及OAEP（SHA256，MGF1 SHA256）加密。
2. `POST /public/bootstrap`，普通JSON `{"ek":"RSA结果Base64"}`。检查外层code=200。
3. 初始化响应data.data用seed前16字节作AES key、后16字节作IV，AES-CBC/PKCS7解密得到 secretKey、iv。
4. 业务请求将明文JSON紧凑序列化并UTF-8编码，AES-CBC加密，key=`secretKey[:16].encode()`、IV=`iv[:16].encode()`，填充PKCS7，密文Base64为data。
5. sign=`HMAC-SHA256(secretKey.encode(), data.encode()).hexdigest()`。请求体 `{"data":"...","sign":"..."}`。
6. 响应若是data/sign，先比较HMAC，再解密；若已是含code的普通JSON则直接判断。最终业务code=200才成功，读取data。

请求头包括 X-Request-Id（UUID）、X-Timestamp（毫秒）、X-Platform=web；登录后 Authorization=`Bearer <token>`。保持同一requests.Session及Cookie。重复明文在固定key/IV下可能得到相同密文，但不能靠重放旧密文替代完整协议。

## 登录/本人资料/退出

| 方法/路径 | 解密后业务参数 | 结果 |
|---|---|---|
| POST `/auth/login` | phone、password | token可能在结果顶层或data.token；保存token、secret、iv、Cookie |
| POST `/user/profile` | 空对象（当前测试准备使用） | 本人资料；用户此前已验证该接口，仍需核对监控账号身份 |
| POST `/auth/logout` | 用户提供过接口，当前生产适配器未实现调用 | 不应在监控测试中调用 |

生产登录已修复为使用同一Session完成bootstrap/login及后续请求。配置账号密码仅用于填充登录框；保存会话不延长服务端有效期。

## 图片

`POST /file/upload/{category}`，multipart/form-data，字段file二进制，Authorization沿用登录会话；这不是data/sign包裹的JSON请求。响应可能为普通code/message/data或加密包，均通过unpack处理。

| category | 用途 |
|---|---|
| ARTICLE_FREE | 免费区图片，含预售时免费区 |
| ARTICLE_PAID | 非预售付费区图片 |
| ARTICLE_APPEND | 追加内容图片 |

data.filePath为提交文章所需的持久对象路径。fileUrl可能含临时签名和过期时间，不能当作持久图片路径保存。上传超时为连接10秒/读取180秒。

## 发布

`POST /article/create`，加密JSON明文：

| 字段 | 意义 |
|---|---|
| title | 标题 |
| summary | 副标题/简介；与统一免费内容不是同一个字段 |
| price / originalPrice | 数字价格 |
| isPreSale | boolean预售 |
| tags | 标签字符串数组 |
| freeContent / freeImages | 免费文字 / ARTICLE_FREE上传返回路径数组 |
| paidContent / paidImages | 非预售、价格大于0时的付费文字 / ARTICLE_PAID路径数组 |
| isDiscountAllowed | boolean允许折扣 |
| isMembershipAllowed / isListed | 当前固定true |
| isPinned / status | 当前固定false / 1 |

预售时不将付费正文和付费图片偷偷移动到免费区，也不提交paidContent/paidImages。非预售价格0时，正文按当前适配器规则与免费内容合并，图片归免费区。返回data为创建的articleNo，统一工具保存为本平台文章ID。

## 追加/修改

`POST /article/append`，明文必需 articleNo、content、images（ARTICLE_APPEND路径数组）。可选 title、summary、originalPrice、isDiscountAllowed、tags；非预售/完成预售使用finishPreSale=true。官网前端同接口支持这些字段，无需猜测 `/article/update`。

标题/简介非空才发送；标签未指定不发送；价格输入留空时统一工具使用已保存原价。当前适配器“originalPrice”对应价格；不是price。本文只描述现有实现，不承诺将非预售重新切回预售。

`POST /article/append/article-info` 为官网追加页读取信息的接口，参数articleNo；已从前端发现，生产尚未调用。

## 置顶/取消置顶

`POST /article/pin` 或 `/article/unpin`，明文 `{"articleNos":["文章编号"]}`，支持数组；code=200成功。

`POST /article/{articleNo}/publish-dashboard` 是发布统计/页面信息查询，官网发送空对象或空参数；不是执行发布的写入接口，不应在追加后无条件再次“发布”。

子账号同步由平台规则处理，统一工具不另调同步接口。用户监控准备见 [料小宝监控测试](料小宝监控测试准备.md)。
