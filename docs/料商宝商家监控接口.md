# 料商宝用户端商家监控（分步测试）

## 登录

`POST https://qwer.lszs.red/lsb/toMobileLogin`

表单字段：`mobile` 手机号、`pwd` 密码。以 `status == 200` 判断成功，不能用 `success`；从字符串 `data` 解析 `uid`、`sid`，并保持 requests.Session 的 Cookie。复用正式登录适配器，不导入测试脚本。

## 关注商家

`GET https://qwer.lszs.red/lsb/getMyGuanZhus`

查询参数：`index` 从1开始、`uid` 当前用户、`sid` 登录会话、`seltype=2`、`selid=` 空字符串。

以 `status == 200` 判断成功，从 `data.lists` 取商家，从 `data.maxPage` 取最大页码。读取所有页面后按 `user_id` 去重；名称不参与唯一性判断。同时完整保存 `s_user_id`、名称、备注、头像等返回字段。尚未确认查询文章应传 `user_id` 还是 `s_user_id`。

## 测试

复制 `tests/liaoshangbao_monitor.example.json` 为同目录的 `liaoshangbao_monitor.local.json`。填写手机号与密码，或填写有效的 uid/sid。不要将本地配置提交到代码库。

在项目根目录运行：

```powershell
& 'D:\ProgramData\Anaconda3\envs\quant312\python.exe' '.\tests\料商宝商家监控测试.py'
```

输出保存到程序目录的 `料商宝关注商家.local.json`。如明确需要复用统一工具中保存的发布账号，可添加 `--use-saved`；默认不自动复用，避免查错账号。

## 商家文章列表（已从主页脚本确认并实测）

`/lsb/userSelds` 是 HTML 商家主页，不是文章 JSON 接口。主页中的 `onDataLoad()` 调用：

`GET https://qwer.lszs.red/lsb/getUserSelds`

参数：`uid`、`sid`、`soid` 为关注商家的 **s_user_id**、`index` 从1开始、`seltype=1`（标题查询）、`selid=` 空字符串。主页 URL 的 `reqTime` 不需要传给列表接口。

响应：`status=200` 成功，即使 `success=false`；`data` 直接是文章数组；`msg` 为总页数字符串（不是关注接口的 data.maxPage）。

字段：`id` 数字文章ID，`s_id` 编码文章ID，`user_id` 商家数字ID，`title` 标题，`short_msg` 简介，`price` 价格，`all_zk` 折扣，`on_seld_top` 是否置顶，`pre_sale` 是否预售，`create_time` 上架时间。完整保留返回字段，不读取付费正文。

测试命令（先配置登录信息）：

```powershell
& 'D:\ProgramData\Anaconda3\envs\quant312\python.exe' '.\tests\料商宝商家监控测试.py' --soid '关注商家的s_user_id'
```

默认初次保留最近100篇，按 `id` 去重、按 `create_time` 降序排列，结果保存为“料商宝监控文章.local.json”。分页读取直到遇到100条非置顶文章或末页，再连同读取到的置顶文章统一排序截取100条；不会把旧置顶文章计入普通文章采集配额。此优化依赖服务端非置顶列表按新到旧排序，尚未验证所有排序边界，不是全历史扫描。

增加 `--watch` 开启持续监控，默认60秒检查，可用 `--interval 30` 调整（至少10秒）。首次100篇建立基线、不提示新增；后续按文章ID检测新增，保存初始数据与后续新增结果。Ctrl+C停止。监控期间只读取最近100篇窗口；两次轮询之间新增超过100篇时可能遗漏，需要缩短间隔。`--pages` 仍可用于指定1到20页的单次接口测试，不能与 `--watch` 同用。

当前测试只查询关注商家及文章列表，不修改关注关系，不发布或修改文章。

## 统一工具接入

正式工具通过 `liaoshangbao_monitor_adapter.py` 接入账号与任务管理，不导入测试脚本。适配器按 `s_user_id` 返回关注商家映射，将 `id/title/create_time/on_seld_top` 转换为统一的文章ID、标题、时间、置顶字段，同时保留原始字段。料商宝、壹料、红料首次基线统一为最近100条。
