# 料商宝商家发布与编辑

域名：`https://qwer.lszs.red/lsb`；实现：`publisher_app/platforms/liaoshangbao.py`。同域用户监控见 [用户监控接口](料商宝商家监控接口.md)。

## 认证与请求头

`POST /toMobileLogin`，form-urlencoded：mobile、pwd。status=200成功，success=false不影响判断。从data的 `uid=...&sid=...` 解析两字段，同时保存Cookie。发布和更新必须使用同一会话。

请求头：Origin为域名，Referer为对应addIndex/updateIndex页面并带uid/sid；X-Requested-With=XMLHttpRequest；移动端User-Agent见适配器。Content-Type及boundary、Content-Length由requests生成，不复制抓包里的固定值。Cookie由Session维护。

## 发布文章

`POST /addPro`，multipart/form-data。按列表保留重复字段，不使用会丢重复键的普通字典。

| 字段 | 类型/意义 |
|---|---|
| uid / sid | 登录用户及会话 |
| title | 标题 |
| title2 | 当前发布请求也带此字段；平台是否使用不以此保证 |
| shortMsg / shortmsg | 副标题/简介，当前统一UI映射subtitle；两个大小写字段均发送 |
| free_content / freeContent | 免费文字，两种命名均发送 |
| content | 付费文字，抓包有重复字段 |
| price | 价格字符串 |
| showLabel | 标签字符串，抓包有重复字段 |
| preSale | 1预售、0非预售 |
| canZK | 1允许折扣、0禁止折扣，与壹料noDiscount相反 |
| tmpFile0、tmpFile1… | 图片文件，最多9张合计 |

其他当前固定字段：onSeld=1、canVip=1、bgimgid=img/a001.png、canBuyCount=0、fsLv=0、allZK=10、canAgain=0、gid=0；playTime/autoSeldTime/autoNoticeTime/freeTime/validTime为空。未传图片也保持multipart格式。

响应示例：`{"status":200,"success":false,"msg":"编码文章ID","data":null}`。保存msg或data的文章ID，不能用success判断。最新免费图片按用户要求与付费图片共用tmpFileN，免费图片先、付费图片后，免费区归属尚未验证，不宣称平台支持独立免费图片区域。

大于1MB的非动画图片可压缩、限制最长边2400，只有压缩后更小才替换上传文件；透明图用PNG，普通图JPEG；不修改用户源文件。上传读取超时180秒，超时后提交结果未知，需人工核对。

## 追加/更新

`POST /updatePro`，同为multipart。uid、sid、pid（编码文章ID）、title、content、price、shortMsg/shortmsg、showLabel、preSale、canZK；固定字段延续抓包，包括customPrice/customCount空、canBuyCount=0、playTime/freeTime/validTime空等。副标题不通过未经确认的title2更新；当前使用shortMsg/shortmsg，最新行为需回归。

price是平台要求的参数。用户不改价格时，从文章映射读取原价并传回，不能发送空价格。标签留空时优先复用记录的原标签；旧记录未知标签则不发送showLabel。未知副标题也不发送空shortMsg。追加内容必须有文字或图片。图片仍tmpFileN、最多9张。响应status=200成功，msg可能为文章ID。

## 置顶/取消置顶

`POST /toSeldTop`，普通表单uid、sid、pid。同一接口**切换**置顶状态，返回msg区分“置顶成功”或“取消置顶成功”。不是幂等的pin/unpin接口，不能盲目重试；当前统一工具两种按钮都调用此切换接口，最终状态应到平台核对。

子账号同步由平台/手机端规则控制，不额外调用同步接口。
