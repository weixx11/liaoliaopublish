# 登录配置

程序目录中的 `登录配置.local.json` 在首次启动时自动创建。分别填写“壹料发布”“料商宝发布”“料小宝发布”“料商宝监控”“料小宝监控”的“账号”和“密码”，不使用的平台留空。例如：

```json
{
  "壹料发布": {"账号": "", "密码": ""},
  "料商宝发布": {"账号": "", "密码": ""},
  "料小宝发布": {"账号": "", "密码": ""},
  "料小宝监控": {"账号": "", "密码": ""},
  "料商宝监控": {"账号": "", "密码": ""}
}
```

账号和密码放在英文双引号内，保留逗号和大括号。保存后重启程序，或在“平台登录”页点击“重新读取登录配置”。程序填充登录框后，由用户点击各平台登录按钮。登录成功后密码框会清空，需要时再次读取配置即可。不会自动登录、自动重试发布，也不会把配置密码写入日志。

这是用户要求的明文配置，请勿分享、上传或随测试包发送。该文件已加入 Git 忽略规则，打包流程不会收集此文件；EXE 首次启动会在自己的目录生成空模板。会话、Cookie 和 token 仍统一保存在“平台会话.local.json”。

壹料/红料的监控用户采用图形码、短信码登录，不适用账号密码配置。

会话可能因为服务端有效期、多端登录互踢或风控而失效，本地保存不能延长服务端有效期。料小宝已修复临时会话登录后 Cookie 丢失的问题；尚未验证它是否是短期失效的唯一原因。若仍频繁失效，应记录具体平台、间隔时间和接口业务错误码后继续排查。
