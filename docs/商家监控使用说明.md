# 商家监控

文章有副标题时，标题列展示“主标题 | 副标题”；标题关键词搜索、详情与复制完整标题均使用拼接后的内容。料商宝读取short_msg，料小宝读取summary，壹料/红料读取列表返回的planSubtitle/planTitle2/title2/subtitle；若列表未返回副标题则仅显示主标题，不把免费正文当作副标题。后续轮询会刷新已缓存文章的标题，不会因副标题变化重复提醒新文章。

搜索商家：在文章列表上方或左侧任务栏的“搜索商家”输入名称、平台或商家ID，两个搜索框同步。文章列表、店铺下拉候选和左侧商家任务均按该关键词筛选，可与文章标题关键词、单店铺选择组合查询。清空商家搜索恢复完整列表；筛选不暂停后台监控。搜索期间全选、取消全选和批量操作只作用于当前显示的商家。

## 料小宝

在“平台登录 → 料小宝用户监控登录”使用用户账号登录。商家发布使用“料小宝商家发布登录”，两者各自建立HTTP会话，分别保存token、密钥和Cookie。监控登录不会覆盖发布账号，发布登录也不会自动加入监控。支持按userId保存多个监控用户；统一存储文件内按用途隔离，监控会话标记purpose=user_monitor。旧版本自动复制的发布会话不再作为监控账号恢复，请在用户监控页重新登录。

在“商家监控”勾选料小宝账号，自动分页加载关注商家，以authorId区分。首次按publishTime倒序保留最近100篇在售文章，作为基线不提醒；后续按articleNo检测新增。勾选、全选、独立暂停、间隔、关键词/店铺筛选、完整标题复制、时间排序、日志及缓存均复用统一界面。

料小宝接口返回顺序不保证按发布时间倒序，目前每轮完整分页核对再取100条。日志显示分页进度；单商家34页的测试约8至10秒，更多商家会增加一轮耗时。网络失败不覆盖该商家基线，不影响已成功返回的其他商家结果。会话过期请回原登录页重新登录。

## 料商宝

在“平台登录 → 料商宝用户监控登录”输入手机号、密码并登录。支持多个账号，会话与壹料、红料统一保存到“平台会话.local.json”的监控账号区域，不保存密码，也不覆盖料商宝商家发布账号。

在“商家监控”勾选料商宝账号后，程序自动分页读取关注商家。任务使用关注列表的 s_user_id 查询文章，商家名称仅用于显示。现有的全选、暂停、立即检查、店铺筛选、标题搜索、排序、复制完整标题、日志和文章缓存全部共用。

每个料商宝商家首次展示最近100篇作为基线，不提醒历史文章；之后默认60秒检查（可按任务调整），按文章ID识别新增。折后价按 price × all_zk ÷ 10 计算；不把折扣为10解释为“禁止折扣”。接口读取最近100篇窗口，极短时间新增超过100篇时存在遗漏风险；置顶分页处理依赖非置顶文章按发布时间倒序返回。详情参考“料商宝商家监控接口.md”。

## 壹料 / 红料

1. 在“平台登录 → 壹料 / 红料用户登录”输入手机号，获取图形验证码、发送短信并登录。每个平台可登录多个用户账号，会话统一保存在“平台会话.local.json”，不保存短信验证码。
2. 打开“商家监控”，选择一个或多个已登录账号。选择后自动读取各账号的关注列表，并为关注商家创建独立任务。已有登录会话失效时，日志会记录接口错误，需要回到登录页重新登录。
3. 新关注商家默认开始监控，每60秒刷新关注列表；取消关注的商家移出任务。手动暂停的任务在刷新关注列表后保持暂停。
4. 账号和商家均支持直接点击勾选，无须按住 Ctrl。商家勾选用于批量操作，运行状态以“状态”列为准。点击商家行“操作”列可独立开始、暂停；也可以勾选商家后使用“开始所选 / 暂停所选”。间隔至少10秒，应用于这次操作的任务。“立即检查”检查勾选的商家一次，不改变暂停状态。
5. 壹料、红料、料商宝首次检查均建立最近100篇文章的基线，按发布时间倒序展示，不弹历史文章提醒；不足100篇时展示接口实际返回数量。壹料/红料继续使用最新文章接口 expertLastPlan，不使用历史文章接口补充。后续按文章ID识别新增文章，跨账号关注同一商家的文章在公共列表中去重。
6. 文章可按上架时间升序、降序排序，按单个店铺筛选，与标题关键词组合查询。表格最多展示500条，最近5000条自动保存到程序目录的“商家监控文章.local.json”，重启自动加载。店铺按平台和商家ID区分。右键或 Ctrl+C 可复制完整标题。
7. 运行日志记录关注列表同步、每个商家的检查数量、新增数量及接口错误。日志保留最近约1000行，可清空。

关闭程序停止监控。重新打开后加载已保存的账号和文章，由用户选择本次监控的账号；商家暂停状态和间隔会保存，新帖基线在本次运行期间保留。底部详情区显示所选商家的完整账号、商家ID、监控状态，或文章完整标题；左侧商家表格支持横向滚动，左右区域可拖动调整宽度。

监控读取用户关注商家和最新文章，不调用发布平台的文章置顶、修改接口。
