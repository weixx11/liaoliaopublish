# 壹料商家端

域名：`https://yapi.njyuelu.cn`。正式实现：`publisher_app/platforms/yiliao.py`，地址表：`publisher_app/config.py`。

除特别说明外均 POST JSON `{"d":业务参数}`，`Content-Type: application/json`；登录后请求头 `Authorization: <token>`，保留 Cookie。响应 `{"c":200,"m":"成功","d":结果}`，非200抛业务错误。

## 登录与商家资料

| 路径 | 参数 | 返回/用途 |
|---|---|---|
| `/mgr/mgr/login` | `account`、`pwd`、`proxyTag:""` | d 保存为 user_data，包含 token、expertId 等，具体随账号返回 |
| `/mgr/sys-user-do/userInfo` | 当前程序无请求体，仍为 POST | d.groupList 为子商户列表，保存 groupRelateName 和 groupRelateId |
| `/plan/mgr-expert-do/expertInfo` | d 为专家ID字符串 | 用户提供过的资料接口，当前正式程序不调用；返回 userId 为 U开头字符串 |
| `/mgr/sys-group/userGroupList` | `tag1:2,groupType:1,userId:<管理端数字ID>` | 旧测试接口，非当前子商户加载方案；不能把专家资料的 U开头 userId 传入此数字字段 |

子商户同步使用 groupRelateId（DL开头专家ID），不是管理端数字userId。

## 图片上传

`POST /resource/rse-img-do/uploads`，multipart/form-data：`files` 二进制，`path=resource`。需要 Authorization，不手动设置 boundary。上传返回地址插入 HTML：

```html
<p>文字</p><p><img src="图片URL" alt="" data-href="" style=""/></p>
```

文字与图片混排必须组成有效HTML，不能把本地路径或附件占位符作为内容提交。免费图片放 summary/freeContent，付费图片放 content。位图或 file URI 的识别由统一编辑器完成。

## 发布

`POST /plan/mgr-do/add`。主要字段：

| 字段 | 说明 |
|---|---|
| id | 新建时空字符串 |
| title / title2 | 标题 / 副标题 |
| summary / freeContent | 统一免费内容转HTML |
| content | 付费正文HTML |
| price / priceReal | 价格字符串 |
| tags / tagsArray | 逗号连接字符串 / 标签数组 |
| expertId | 当前登录专家ID |
| noDiscount | 0允许折扣，1禁止折扣；使用枚举映射 |
| presell | 1预售，0非预售 |
| publicTime | 当前时间，yyyy-MM-dd HH:mm:ss |
| beginTime / endTime | 当前适配器使用未来24小时时间，避免更新后过期不可见 |

当前固定字段：appPush=1、planPackAuto=1、planPacks=""、notifyAuto=0、items=""、title2默认空、free=0、needPay=1、activityId=null、sportsId=4、tag1/tag2/labelIds=""、playType="9001"、updateTimeShow=0。完整结构以适配器publish函数为准。返回 d.id 作为文章ID。

## 更新和子账号同步

`POST /plan/mgr-do/modifyContent`：id、expertId、content，以及显式修改的title/title2、tags、price/priceReal等。当前程序仍发送 compType="1"、lotteryType=6、status=0、verifyStatus=2、sportsId=4、playType="9001" 等平台要求的原有结构。仅追加内容时不能发送空summary/freeContent；未知原标签、副标题时不发送相应空字段。填写免费内容当前是修改字段，尚无独立免费内容追加协议，不应承诺服务端会自动拼接。

发布后按勾选的子账号同步；更新成功后自动调用更新同步接口。

| 用途 | 当前配置路径 | d参数 |
|---|---|---|
| 发布同步 | `/plan/mgr-do/planSynAdd` | planId、expertIdList 数组 |
| 更新同步 | `/plan/mgr-do/planSynUpdate` | planId |

## 置顶/取消置顶

与更新同路径 `/plan/mgr-do/modifyContent`，独立请求 `{"d":{"id":123,"weight":5000}}` 置顶，weight=0取消。响应d=true为成功。不要将此操作误作删除文章。
